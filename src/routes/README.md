# 🗺️ TanStack Start Routing Guide

This application leverages **TanStack Start** with full SSR hydration and file-based routing.

## 📁 Route Conventions

| File Path | URL Route | Description |
| :--- | :--- | :--- |
| `src/routes/__root.tsx` | App Shell | Global HTML structure, meta tags, fonts, stylesheets, and router context. |
| `src/routes/index.tsx` | `/` | Root entrypoint rendering `RailApp.jsx`. |

## 🧭 In-App Screen State Architecture
While top-level routing is handled by TanStack Router, the inner screens are seamlessly switched via dynamic reactive state inside `RailApp.jsx`:
- `"search"`: Smart station search, nearest hub locator, Tatkal countdown banner, and radar.
- `"results"`: Train listings, multi-class fares, and seat confirmation probabilities.
- `"booking"`: Passenger selection, berth preference matrix, and payment checkout.
- `"confirmation"`: Digital receipt, confirmed PNR, and action shortcuts.
- `"trips"`: Digital e-tickets with QR codes, live route tracking, and TDR refunds.
- `"explore"`: Interactive railway tools, trending circuits carousel, and tourism packages.
- `"help"`: Helpline 139, grievance tracker, and interactive FAQ accordions.
- `"account"`: Master passenger list, KYC verification, and notification settings.

> ⚠️ **Note**: `routeTree.gen.ts` is automatically generated by TanStack Router. Do not edit it manually.
